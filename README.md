# Sky & Stream Science Lab

An interactive North Carolina Grade 5 science app covering weather, climate, and the water cycle.

## Classroom use

The app runs entirely in the browser and does not collect student names, accounts, or responses. Lab-visit progress is stored only on the current device.

## Local development

```bash
npm install
npm run dev
```

## Standards

Activities address North Carolina Earth and Space Science objectives ESS.5.1.1–ESS.5.1.4.
